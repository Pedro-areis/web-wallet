# 0001. Java 21 como versão do projeto

## Contexto
O backend declarava uma versão do Java que não era a LTS estável usada pelo Spring Boot 3.5.7. A Fase 0 precisa fixar a versão para que o build seja reproduzível.

## Decisão
Usar **Java 21 (LTS)** no backend, fixado no `pom.xml` (`java.version`).

## Alternativas consideradas
- **Java 25 (LTS mais recente):** suporte mais longo, porém o ecossistema (Spring Boot 3.5, Lombok, Testcontainers, plugins Maven) ainda tem menos validação, com mais risco de incompatibilidade sem benefício real para o projeto.
- **Java 21:** suportado e estável com a stack atual; menor risco.

## Consequências
Build e CI usam JDK 21. Um upgrade futuro para 25 pode ser avaliado junto com o Spring Boot 4 (Fase 8).
