# Web Wallet: frontend

React 19, TypeScript, Vite 7 e Tailwind 4.

## Configuração

Copie o exemplo e ajuste a URL da API, se necessário:

```bash
cp .env.example .env
```

| Variável | Descrição |
|---|---|
| `VITE_API_URL` | URL base da API (padrão local: `http://localhost:8080/api/`) |

## Comandos

```bash
npm ci
npm run dev
npm run build
npm run lint
```
